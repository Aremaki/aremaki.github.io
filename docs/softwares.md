Open-source softwares I have led across research projects.

=== card
    [📄 **LongBEL**](https://huggingface.co/collections/Aremaki/longbel)
    ---
    [Code](https://github.com/Aremaki/LongBEL){ .button-link .purple-button } • [Article](https://openreview.net/forum?id=5EKQjSuR3y#discussion){ .button-link .blue-button } • [Models](https://huggingface.co/collections/Aremaki/longbel){ .button-link .dark-yellow-button }

    LongBEL (Long-Context and Document-Consistent Biomedical Entity Linking) is a generative framework for biomedical entity linking that uses document context and memory of previous normalizations to improve entity disambiguation and ensure consistent predictions across a document.


=== card
    [🤖 **SynCABEL**](https://huggingface.co/collections/Aremaki/syncabel)
    ---
    [Code](https://github.com/Aremaki/SynCABEL){ .button-link .purple-button } • [Article](https://doi.org/10.24963/ijcai.2026/763){ .button-link .blue-button } • [Models](https://huggingface.co/collections/Aremaki/syncabel){ .button-link .dark-yellow-button } • [Datasets](https://huggingface.co/datasets/Aremaki/SynCABEL){ .button-link .green-button } • [Poster](/assets/files/2026_08_15_IJCAI.pdf){ .button-link .pink-button }

    SynCABEL (Synthetic Contextualized Augmentation for Biomedical Entity Linking) is a novel method that enhances biomedical entity linking (BEL) by using LLM-generated contextual sentences to augment training data for context-aware BEL models.

=== card
    [🧪 **BioMedics**](https://github.com/Aremaki/BioMedics)
    ---
    [Code](https://github.com/Aremaki/BioMedics){ .button-link .purple-button } • [Article](https://medinform.jmir.org/2025/1/e68704){ .button-link .blue-button } • [Poster](/assets/files/2025_02_01_SaintMalo.pdf){ .button-link .pink-button }

    BioMedics is an NLP system that transforms unstructured French clinical notes into structured data. It performs named entity recognition, qualification, and entity linking for drugs and laboratory tests.

=== card

    ---
    [Code](https://github.com/aphp/edsteva){ .button-link .blue-button } • [Article](https://www.medrxiv.org/content/10.1101/2023.08.17.23294220v1){ .button-link .pink-button }
